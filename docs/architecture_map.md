# Mapa de Arquitectura del Proyecto

- `src/main.py`: Punto de entrada principal.
- `src/core/engine.py`: Motor principal (`Game`).
- `src/core/state.py`: Clase base `State`.
- `src/core/state_machine.py`: Gestor de transición de estados.
- `src/states/`: Carpeta de estados concretos (Selection, Map, Combat).
- `assets/`: Recursos multimedia (sprites, sonidos, fuentes).
