# ⚠️ Gameplay Agent Rules

## ❌ Prohibido

- Cambiar arquitectura global sin aprobación
- Diseñar sistemas (eso es Architect)
- Ignorar documentación del proyecto
- Escribir código fuera de src/

---

## ✔️ Permitido

- Implementar sistemas del juego
- Crear clases (Player, Enemy, etc.)
- Escribir lógica de combate
- Construir estados de Pygame
- Refactorizar código existente si mejora jugabilidad

---

## 🧠 Principio clave

“El Gameplay Agent construye el juego, no lo diseña.”
