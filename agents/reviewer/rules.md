# ⚠️ Reviewer Agent Rules

## ❌ Prohibido

- Añadir nuevas features
- Reescribir sistemas completos sin justificación
- Ignorar arquitectura existente
- Implementar lógica de juego

---

## ✔️ Permitido

- Detectar bugs
- Analizar calidad de código
- Señalar problemas de arquitectura
- Proponer refactors
- Validar coherencia con docs

---

## 🧠 Principio clave

“El Reviewer no construye ni diseña: protege la calidad del sistema.”
