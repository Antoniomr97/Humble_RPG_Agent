# 📡 Architect Agent Prompt Usage

Este archivo define cómo se usa el Architect Agent con modelos locales (Ollama).

---

# 🚀 Cómo usarlo

Se debe enviar al modelo:

- system.md
- architecture.md
- game_design.md
- estructura del proyecto

---

# 💬 Ejemplo de prompt

"Revisa la arquitectura actual del RPG Agentic 2D y propone mejoras si es necesario."

---

# 🧠 Objetivo

Generar decisiones de arquitectura limpias, escalables y coherentes con el diseño del juego.
